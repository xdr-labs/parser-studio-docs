# I tried a different mapping and want the old one back

**Situation:** Auto Parser extracted the data, but you are experimenting with different field names or using different source examples. Rather than overwriting the same working draft repeatedly, save versions as you go.

## Walkthrough

1. In **Auto Parser**, paste and analyze your sample, then review its mappings.
2. Click **Local Versions** in the top toolbar.
3. Save a descriptive snapshot, for example "Firewall before mapping change".
4. Return to **Map Fields**, change the desired destination or value type, and re-check the examples.
5. Open **Local Versions** again and save another named snapshot.
6. Use the comparison/revision tools to inspect what changed. Choose **Restore** on the version you prefer.
7. After restoring, repeat **Analyze Logs** and the necessary review steps before final file generation. Restoring a previous version is not a new test result.

## Expected review outcome

You can recover your earlier source and draft settings for that browser environment, then revalidate your preferred mapping.

## Recovery path

Local Versions is **browser-local**, not a shared backup. If you clear browser data or switch environments, saved versions may not be available. Keep important reviewed output files separately.

## Local Versions in the current Web UI

The local workspace offers **Save Version**, **Compare Versions**, **Restore**, and Delete actions, with **30** browser-local checkpoints at most. Original log samples in browser storage are **not encrypted by Parser Studio**, and version history is not synchronized with the server.
