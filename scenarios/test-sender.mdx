# I want to generate more varied test logs

**Situation:** You already have representative logs and want a script that updates timestamps and selected values for repeatable testing. You do **not** need to understand Python to use the downloaded file.

## Walkthrough

### 1. Paste representative logs

In **Auto Parser → Add Logs**, paste the sample you intend to use for tests. Review and replace any sensitive data **before generating the script**. The source text is embedded as base64, **not encrypted**.

### 2. Download the script

Expand **Generate a Python Test Sender**, then click **Download Python Test Sender (.py)**. The browser downloads `parser_studio_test_sender.py`. The browser does **not** send any test traffic by downloading the file.

### 3. Run it on a computer you control

Use Python 3:

```bash
python3 parser_studio_test_sender.py
```

The script interactively asks for the intended receiving host's IP address, port, **UDP** or **TCP** mode, event count (default **60**, maximum **600**) and explicit **YES** confirmation. Use only a destination you are authorized to test.

### 4. Inspect the results

The script sends **at most one event per second**, using the local computer clock for recognized timestamps. Recognized IP, user, email and location values may be varied with fictional values. Other values may remain unchanged.

The script does not independently confirm that a receiver processed the events. Check the local receiver or test environment separately.

## Expected review outcome

You have a self-contained Python file based on your sample; when you run it, it asks where and how to send events, then stops after the selected finite count or Ctrl-C.

## Recovery path

If the receiver shows no events, check the entered address, port, mode and receiving application first. If the sample is confidential, do not share the generated file: base64 is recoverable text.

## Current downloaded sender behavior

The generated Python 3 script uses the standard library, prompts for a sensor IP, destination port, UDP/TCP, and event count, and sends **at most one event per second**. Defaults are **60 events**; transmission requires explicit **YES** confirmation and can be stopped by Ctrl-C.

The .py file includes base64-encoded sample logs (**not encrypted**). Unknown source values may remain unchanged. The browser does not install parser files, send test traffic, or check sensor reception.
