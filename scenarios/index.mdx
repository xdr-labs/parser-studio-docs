# Choose what happened after analyzing your logs

**Everyone starts in Auto Parser:** paste a few complete source events and click **Analyze Logs**. You do not have to identify a log format.

## ChatGPT Assisted Parser: recover or verify a difficult case

Use the left-side **ChatGPT Assisted Parser** menu when the automatic path cannot safely interpret the source or proposes a change that needs independent checking.

<CardGroup cols={2}>
  <Card title="Nothing in my log was understood" icon="comments" href="/scenarios/unknown-log">
    Create a manually reviewed, masked prompt and paste the restricted JSON result back.
  </Card>
  <Card title="One missing field needs a new rule" icon="wrench" href="/scenarios/recipe-ai">
    Preserve correct values and request one narrow change.
  </Card>
  <Card title="ChatGPT's answer was rejected" icon="circle-xmark" href="/scenarios/ai-invalid-response">
    Read the error and ask for a supported structured correction.
  </Card>
  <Card title="The suggested fix needs additional proof" icon="check-double" href="/scenarios/ai-test-change">
    Use other events as independent tests before approving the result.
  </Card>
</CardGroup>
