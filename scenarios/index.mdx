# Which situation are you in?

**Start in Auto Parser, paste the logs, then click Analyze Logs.** Once the result appears, choose the matching guide below.

<CardGroup cols={2}>
  <Card title="Everything parsed correctly" icon="circle-check" href="/quickstart">Review Fields → Map Fields → Create Parser → download.</Card>
  <Card title="One part of a log is missing" icon="triangle-exclamation" href="/scenarios/partial-event">Use Problem to review, read the highlighted text and try the recommended fix.</Card>
  <Card title="Nothing can be understood" icon="comments" href="/scenarios/unknown-log">Switch to ChatGPT Assisted Parser and review a masked example.</Card>
  <Card title="One product, several event types" icon="layer-group" href="/scenarios/mixed-events">Analyze them together, then confirm whether a combined parser is supported.</Card>
  <Card title="Values have no field names" icon="table" href="/scenarios/csv-with-spec">Keep temporary columns or enter names from the source document.</Card>
  <Card title="Extracted fields have wrong destinations" icon="arrow-left-right" href="/scenarios/normalization">Correct mappings without changing the original event.</Card>
</CardGroup>

## How to use these guides

Every scenario follows the same pattern: **what happened → where to click → what to check → what to do if that does not work**. All sample events and UI screenshots use fictional data.

<Note>
  If you simply want to create your first parser, skip the format examples and [start with Quickstart](/quickstart).
</Note>
