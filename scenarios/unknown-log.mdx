# Parser Studio cannot understand this log. What do I do?

**Watch:** [English tutorial using published real log samples](/videos/unknown).

**Situation:** You pasted logs, clicked **Analyze Logs**, and the result says **0 of N log events parsed completely**, or the entire text is marked as needing review. You do not need to identify a log format before starting the recovery workflow.

## Walkthrough

1. Stay under **Auto Parser → Add Logs**. Confirm you pasted complete source records, then click **Analyze Logs**.
2. Read the result. If it needs attention, use **Problem to review** to select an event.
3. Check **Original event**, **What needs attention**, and **Recommended fix**.
4. If a supported on-screen fix such as **Use extracted fields** is offered, review it first. If no safe local repair is available, click **Fix with ChatGPT** or select **ChatGPT Assisted Parser** on the left.
5. In **Original local logs**, keep the source for local checking. Describe the fields you need in **What do you want Parser Studio to find?**.
6. Review and mask the separate **Redacted example to copy to ChatGPT**.
7. Click **Prepare ChatGPT Prompt** → **Copy Prompt**, then paste that prompt into ChatGPT yourself.
8. Ask for **supported ParserRecipe v0.2 JSON**, return the response to **3. Paste the ChatGPT result**, then click **Check ChatGPT Result**.
9. If Parser Studio requests additional test logs, provide different examples, check the comparison and approve only a passing supported change.
10. Return to Auto Parser and re-review all records before mapping and generation.

*Use this menu when automatic analysis cannot safely understand the source. Nothing is automatically sent to ChatGPT.*

## Expected review outcome

You either obtain a supported, independently reviewed proposal or retain a clear unsupported status. Neither result silently discards the original logs.

## Recovery path

If the ChatGPT response contains arbitrary executable code, invalid schema or an unsupported transformation, request a narrower supported structured proposal. If no supported solution is available, preserve the samples and do not claim a parser was created.
