# My firewall logs were recognized. What next?

**Situation:** You copied firewall events from a device, pasted them into Parser Studio and clicked **Analyze Logs**. The result says all events were parsed completely. You do not need to identify their format.

## Practice sample

```json
{"time":"2026-10-18T04:10:11Z","type":"traffic","action":"allow","source":{"ip":"192.0.2.11"},"destination":{"ip":"198.51.100.15","port":443},"policy":"web-access"}
{"time":"2026-10-18T04:11:12Z","type":"traffic","action":"block","source":{"ip":"192.0.2.12"},"destination":{"ip":"203.0.113.6","port":22},"policy":"deny-ssh"}
```

## Walkthrough

1. Select **Auto Parser**, paste both lines in **Add Logs**, and press **Analyze Logs**.
2. Check the event count. If it reports **2 of 2 log events parsed completely**, click **Review Fields**.
3. Under **Choose a source event**, pick Event 1 and Event 2. Check that source address, destination address, port, action and policy match the original values.
4. Click **Map Fields**. Review the destination name and value type of each important field. Do not confuse nested source and destination addresses.
5. Check **Must fix before continuing**. If it is **0**, click **Create Parser**.
6. Choose **Run Final Test & Create Files**. Download the file pair when the final check succeeds.

<figure className="ps-shot"><img src="/images/03-review-fields.png" alt="Review Fields with original and extracted values" /><figcaption>The important task is confirming the correct values, not recognizing JSON syntax.</figcaption></figure>

## Expected review outcome

Both events remain accounted for, and fields retain the same values as the source. A successful final generation produces a reviewed parser logic file and companion configuration.

## Recovery path

If a nested address appears to be missing, return to **Review Fields** and inspect the original source path. If the problem is only the output destination, correct it in **Map Fields**. If the issue is an unparsed section, use [the partial-event guide](/scenarios/partial-event).
