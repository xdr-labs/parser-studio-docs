## What should I do after Analyze Logs?

You start the **same way in every case**: open **Auto Parser**, paste logs, and press **Analyze Logs**. The next step depends on what the result says.

## Current public Parser Studio tools

The product exposes **Auto Parser** and **ChatGPT Assisted Parser** only. The old Wizard and Workbench are not user navigation paths.

- **Parser identity:** Enter manufacturer and product, with optional version and **Parser listener port (.conf)** (default **6801**). [Configure your parser](/workflows/parser-setup).
- **Stellar Cyber 7.0:** Review target names, data types, original values and vendor-only fields rather than choosing old mapping schemas.
- **Up to 10 log types:** Click **Add Another Log Type** for Traffic, Threat, User and other types from one product.
- **Local Versions:** Save, compare, and restore up to **30** browser-local checkpoints. [Learn more](/workflows/local-versions).
- **Original source boundaries:** Explicitly mark relay prefix/postfix text, or declare known forwarder names. Upload original files when CRLF or exact UTF-8 byte offsets matter.
- **Python Test Sender:** Optionally generate an offline standard-library Python script, with explicit operator input before sending.
- **Input limit:** 64 KiB / 500 logical events per analysis. No browser DP upload, automatic sensor transmission or live target verification.
