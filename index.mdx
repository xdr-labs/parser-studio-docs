## What should I do after Analyze Logs?

You start the **same way in every case**: open **Auto Parser**, paste logs, and press **Analyze Logs**. The next step depends on what the result says.

<CardGroup cols={2}>
  <Card title="Everything was parsed" icon="circle-check" href="/quickstart">
    Continue to Review Fields → Map Fields → Create Parser. You do not need to change formats or write rules.
  </Card>
  <Card title="Some text needs attention" icon="triangle-exclamation" href="/scenarios/partial-event">
    Select the flagged event, inspect the highlighted section, and use the recommended fix.
  </Card>
  <Card title="Parser Studio does not understand my logs" icon="comments" href="/workflows/chatgpt-assisted">
    Use ChatGPT Assisted Parser, prepare a masked example, and review the suggested solution.
  </Card>
  <Card title="My product has several log types" icon="layer-group" href="/scenarios/mixed-events">
    Paste representative examples of all types, review the event counts, and choose a combined or separate draft according to the supported result.
  </Card>
</CardGroup>
