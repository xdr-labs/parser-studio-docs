# Create Parser: test, then download

This is the **fourth and final** Auto Parser stage. The normal user should not edit Ruby or configuration text here.

<figure className="ps-shot">
  <img src="/images/05-create-parser.png" alt="Create Parser stage with sample counts and Run Final Test and Create Files action" />
  <figcaption>The example has 2 source events, 2 parsed successfully and 0 needing fixes.</figcaption>
</figure>

## To finish a successful analysis

1. Confirm **Sample logs**, **Parsed successfully**, **Ready to output**, and **Need fixing**.
2. If **Need fixing** is **0**, click **Run Final Test & Create Files**.
3. Wait for the result. When generation succeeds, download the parser logic file and its matching `.conf` configuration file. You can also download a package if offered.
4. Keep those files together with your source sample and the field mapping decisions.

Parser Studio checks returned files' identity and integrity. The final test is **not the same thing as the earlier Analyze Logs button**: it also checks the reviewed mapping and current generator compatibility.

## If nothing is downloaded

Do not keep pressing the button without reading the result.

| Screen result | What to do |
| --- | --- |
| **Need fixing** is not 0 | Click **Map Fields** and resolve mapping problems; if extraction was wrong, go back to Review Fields |
| **One or more sample logs need review** | Return to the highlighted event and follow its **Recommended fix** |
| **Parser creation service is unavailable** | Check the local authoring service; your analyzed fields remain available |
| **Unsupported format or compiler response** | Keep the existing review state, use the available supported path or separate the source groups |
| **Checksum or package integrity failure** | Do not use the mismatched file; regenerate after the service issue is resolved |

## What do I actually receive?

| File | How to understand it |
| --- | --- |
| Extensionless Ruby parser logic | The reviewed parsing instructions |
| Companion `.conf` file | Configuration produced for the same parser draft |
| Optional archive | A package of the reviewed generated files |

<Note>
  A **passing sample and downloadable draft** mean the selected records and current generator checks succeeded. Test other representative log events before treating it as sufficient for your wider log population.
</Note>
