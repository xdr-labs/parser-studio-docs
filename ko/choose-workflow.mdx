# Analyze Logs 이후 어떤 작업을 해야 하나요?

**모든 사용자는 Auto Parser에서 출발합니다.** 샘플을 붙여 넣고 **Analyze Logs**를 누른 결과에 따라 다음 작업이 달라집니다.

  <Card title="모든 이벤트가 완전 파싱됨" icon="circle-check" href="/ko/scenarios/auto-success">

  </Card>
  <Card title="일부 값 또는 텍스트가 남음" icon="triangle-exclamation" href="/ko/scenarios/partial-event">
    Problem to review에서 원본의 미파싱 영역을 확인하고 이미 찾은 필드를 보존합니다.
  </Card>
  <Card title="로그를 전혀 이해하지 못함" icon="comments" href="/ko/scenarios/unknown-log">
    안전한 규칙이 없으면 Fix with ChatGPT 또는 ChatGPT Assisted Parser를 사용합니다.
  </Card>
  <Card title="한 제품의 로그 유형이 여러 개" icon="layers" href="/ko/scenarios/mixed-events">

  </Card>
</CardGroup>

## 진단 화면에서 확인할 항목

1. **파싱 완료 수 / 전체 이벤트 수** — 일부만 성공한 결과를 전체 성공으로 보지 않습니다.
2. **Problem to review** — 어떤 이벤트의 어느 원본 부분이 남았는지 확인합니다.
3. **Values already found** — 이미 인식된 필드 값이 추가 수정 후에도 유지되는지 검증합니다.
4. **Recommended fix** — 제품이 제공한 내장 복구 기능이 있으면 ChatGPT보다 먼저 고려합니다.
5. **Original event / Text not yet assigned to fields** — 남아 있는 원본 영역을 기본 분석 결과 안에서 확인합니다. 별도의 Tools & Diagnostics 메뉴는 없습니다.

<Warning>
  검증을 통과하기 위해 문제 있는 로그를 삭제하지 마세요. 미지원 형식이나 서로 다른 이벤트 유형이 남아 있다면 그대로 보존하고 별도 검토해야 합니다.
</Warning>
