# Python Test Sender: 현재 로그를 재생하는 독립 스크립트

**목적:** 작성한 파서의 원본 로그 형식으로 반복 테스트 데이터를 전송할 때 사용할 수 있는 **로컬 Python 3 스크립트**를 다운로드합니다. 브라우저 자체가 센서에 로그를 보내지는 않습니다.

## 따라 하기

1. Auto Parser의 **Add Logs**에 대표 이벤트를 넣습니다.
2. **Generate a Python Test Sender**를 펼칩니다.
3. **Download Python Test Sender (.py)**를 누릅니다.
4. 소유자가 관리하는 테스트 PC에서 생성된 Python 파일을 실행합니다.
5. 프로그램의 질문에 따라 **센서 IP**, **목적지 포트**, **UDP/TCP**, **전송 이벤트 수**를 입력합니다.
6. 프로그램에서 **YES**를 입력해야 실제 전송이 시작됩니다.

## 예상 결과

- 추가 pip 모듈 없이 Python **표준 라이브러리**로 실행합니다.
- 기본 **60개 이벤트**, **초당 최대 1건**의 속도로 전송합니다.
- 지원되는 타임스탬프·IP·사용자·이메일·위치 필드를 기록별로 변형하며, 문법이 불명확한 값은 변경하지 않을 수 있습니다.
- **Ctrl+C**로 중지할 수 있습니다.

## 복구 방법

생성된 Python 파일에는 샘플 로그가 base64로 포함되며 **암호화된 것이 아닙니다**. 외부에 공유하기 전에 민감한 값을 제거하세요. 제품은 자동으로 DP에 업로드하거나 센서 수신 결과를 확인하지 않으며, 권한이 있는 테스트 대상에만 전송해야 합니다.
