# Local Versions: 시도한 결과를 비교하고 복원하기

**상황:** 필드를 수정했다가 이전 매핑으로 돌아가거나, 같은 장비의 파서 후보 V1과 V2를 비교하고 싶습니다.

## 따라 하기

1. 화면 상단의 **Local Versions**를 엽니다.
2. **Version name**에 Before mapping changes 등의 이름을 지정합니다.
3. **Save Version**을 눌러 현재 로그 유형 이름, 샘플, 파서 규칙과 매핑을 저장합니다.
4. 설정을 변경한 후 새 이름으로 한 번 더 저장합니다.
5. **Compare Versions**에서 Version A와 Version B를 선택해 차이를 확인합니다.
6. 필요하면 저장한 버전의 **Restore**로 작업 상태를 복원합니다.

![로컬 버전 저장 UI](/images/current-07-local-versions.png)

## 예상 결과

최대 **30개**의 로컬 버전을 같은 브라우저 프로필·사이트 출처에 보관하고 비교할 수 있습니다. 서버 계정에 동기화되는 버전 기록은 아닙니다.

## 복구 방법

브라우저 데이터 삭제, 개인 모드 정리, 다른 브라우저 프로필 전환 시 기록이 보이지 않을 수 있습니다. 저장된 로그는 Parser Studio가 별도로 암호화하지 않으므로 공유 PC에서 주의하세요.
