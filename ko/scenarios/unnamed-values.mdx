# CSV에 값만 있고 필드명이 없을 때

**상황:** 로그 한 줄은 쉼표나 다른 구분자로 여러 값이 나뉘지만, 어떤 값이 어떤 필드인지 확실한 헤더가 없습니다.

## 연습용 예시

~~~text
allow,192.0.2.10,198.51.100.10,443
deny,192.0.2.11,203.0.113.20,22
~~~

## 따라 하기

1. Auto Parser에 두 줄을 넣고 **Analyze Logs**를 누릅니다.
2. **Values found, but this log does not include field names**가 표시되면 값이 보존됐는지 확인합니다.
3. 문서화된 스키마를 모른다면 **Keep all N values with temporary names**를 눌러 field_001, field_002 등 임시 이름을 사용합니다.
4. 신뢰할 수 있는 필드 순서 문서가 있다면 **Names to give each value**에 열 개수와 순서대로 이름을 입력합니다.
5. **Character between the values**에서 실제 구분자를 확인하고 **I Confirm These CSV Column Names**를 누릅니다.
6. **Review Fields → Map Fields**에서 원본 값과 임시 이름의 대응을 검증합니다.

## 예상 결과

모든 열이 손실 없이 보존되며, 임시 이름은 문서가 확보되면 나중에 검토해 수정할 수 있습니다.

## 복구 방법

열 개수가 줄마다 다르거나 인용부호 처리 규칙이 불안정하면 임의로 열을 이동시키지 말고 같은 구조끼리 샘플을 나눕니다. 파서는 누락된 헤더 의미를 장비명만으로 추측하지 않습니다.
