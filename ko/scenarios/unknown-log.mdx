# 아무것도 인식되지 않은 로그

**상황:** Analyze Logs의 전체 이벤트가 미파싱 상태입니다. 원본 필드 일부가 generic 값으로만 추출되어 있을 수도 있습니다.

## 따라 하기

1. **Auto Parser**에 원본 Snort 로그를 넣고 **Analyze Logs**를 누릅니다.
2. **Problem to review**에서 **Original event**, **Text not yet assigned to fields**, **Values already found**를 확인합니다.
3. 제품이 안전한 내장 수정 기능을 제안하는지 먼저 확인합니다.
4. 해결되지 않으면 **Fix with ChatGPT**를 누르거나 좌측의 **ChatGPT Assisted Parser** 메뉴를 엽니다.
5. **Original local logs**에 입력한 원문이 프롬프트에 그대로 포함됩니다. 민감정보는 **Prepare ChatGPT Prompt** 이전에 원본에서 직접 수정하거나 삭제합니다. 별도 Redacted example 입력 영역은 없습니다.
6. **Prepare ChatGPT Prompt → Copy Prompt**로 수동 요청을 보냅니다.
7. 응답을 제품이 요구하는 JSON 형식으로 붙여 넣고 **Check ChatGPT Result**를 실행합니다.
8. 서로 다른 로그로 테스트한 다음 승인하고, 원래 이벤트를 다시 검토합니다.

## 예상 결과

지원되는 제안과 독립 검증이 가능하면 복구를 적용할 수 있습니다. 실패하면 원본을 보존하고 미지원 상태로 남겨야 합니다.

## 복구 방법

ChatGPT가 임의 Ruby·Python 코드나 지원하지 않는 형식을 반환하면 실행하지 마세요. [제안 오류 해결](/ko/scenarios/ai-invalid-response)을 참고하세요.
