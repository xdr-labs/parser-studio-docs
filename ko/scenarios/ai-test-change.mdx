# ChatGPT가 제안한 규칙은 다른 로그에서도 작동하나요?

**상황:** 원본 한 건은 파싱되지만 다른 날짜·IP·사용자·메시지 유형에서는 실패할 수 있습니다.

## 따라 하기

1. 변경 내용을 **Check ChatGPT Result** 또는 해당 미파싱 영역 복구 패널에서 검토합니다.
2. 같은 제품의 다른 원본 이벤트를 최소 여러 건 확보합니다. 최초 요청에 사용한 동일 로그를 다시 붙여 넣지 않습니다.
3. **Additional test logs**에 새 예시를 입력합니다.
4. **Confirm different test examples**를 선택한 다음 **Test Proposed Fix**를 실행합니다.
5. 기존 원본 값 보존·남은 미파싱 영역·추가 로그 결과가 모두 유지되는지 확인합니다.
6. 전체 테스트가 통과한 경우에만 **Approve tested fix**를 선택하고 규칙을 적용합니다.

## 예상 결과

원본과 별도의 로그 모두에서 의미 있는 값이 손실되지 않은 후보만 파서 변경에 적용됩니다.

## 복구 방법

규칙이 다른 이벤트에서 일부 필드를 누락시키면 승인하지 마세요. 정확한 실패 이벤트와 수정된 마스킹 예시로 제안을 다시 요청하세요.
