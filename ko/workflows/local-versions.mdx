# Local Versions: 파서 시도 기록을 관리하기

오른쪽 위 **Local Versions**에서 현재 작업 상태를 최대 **30개**까지 같은 브라우저 프로필에 저장할 수 있습니다.

![버전 저장·비교 화면](/images/current-07-local-versions.png)

## 따라 하기

1. Auto Parser에 로그 유형과 샘플, 규칙, 매핑을 준비합니다.
2. **Local Versions**를 엽니다.
3. **Version name**에 기억하기 쉬운 이름을 입력하고 **Save Version**을 누릅니다.
4. 작업 내용을 수정하고 다른 이름으로 다시 저장합니다.
5. **Compare Versions**에서 Version A와 Version B를 골라 변경된 로그·규칙·매핑을 검토합니다.
6. 필요한 시점으로 되돌아가려면 해당 버전의 **Restore**를 사용합니다.

## 저장 범위와 보안

- 서버 계정이나 다른 컴퓨터로 동기화되지 않습니다.
- 해당 브라우저 **프로필과 웹사이트 출처**에서만 보입니다.
- 원본 로그와 필드 규칙을 포함할 수 있으며 제품이 별도로 암호화하지 않습니다.
- 브라우저 사이트 데이터 삭제, 사생활 모드 종료, 다른 프로필 이용 시 기록이 없어질 수 있습니다.
- 손상·미검증 버전은 복원 대상에서 제외될 수 있습니다.

## 자주 하는 실수

Save Version을 누르지 않은 채 브라우저를 종료하면 비교 가능한 체크포인트가 없을 수 있습니다. 외부 파일로 보관해야 한다면 생성 결과를 적절히 보호하고 원본 로그의 기밀성을 고려하세요.
