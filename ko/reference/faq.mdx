# 자주 묻는 질문

## 로그가 CEF인지 JSON인지 알아야 하나요?

아니요. **Auto Parser → Add Logs → Analyze Logs**로 시작하세요. 형식 선택 없이 분석 결과와 필요한 추가 동작을 알려줍니다.

## 일부만 파싱되면 나머지 부분을 따로 처리할 수 있나요?

네. 진단 화면에서 **Text not yet assigned to fields**와 **Values already found**를 구분합니다. 필요하면 **Re-analyze difficult logs** 및 **Fix with ChatGPT**로 추가 규칙을 검토합니다. 검증이 안 된 규칙은 적용하지 않습니다.

## ChatGPT가 자동으로 고객 로그를 받나요?

아니요. **Prepare ChatGPT Prompt → Copy Prompt**를 통해 사용자가 공유할 데이터를 검토·마스킹하고 직접 복사합니다. Auto Parser 자체도 자동으로 외부 AI에 원본을 보내지 않습니다.

## 여러 로그 타입을 하나의 파서로 만들 수 있나요?

**Add Another Log Type**으로 최대 10개 유형을 입력할 수 있고, 지원되는 원본과 확인된 분기 조건에 한해 하나의 파서 프로젝트에서 검증할 수 있습니다. 결과가 100%가 아니라면 경고를 무시하지 마세요.

## Stellar Cyber 버전은 무엇을 기준으로 매핑하나요?

문서에서 설명하는 공개 UI의 권고 사전은 **Stellar Cyber 7.0**입니다. 실제 타깃 호환 여부는 별도 검증이 필요합니다.

## 기본 포트 6801은 어디에 쓰나요?

**Parser listener port (.conf)**로 생성할 CONF의 수신 포트를 지정합니다. 실제 수신 시스템과 충돌 여부는 배포 전에 확인해야 합니다.

## 다운로드한 파서가 자동으로 설치되나요?

아닙니다. **Download Parser Package**는 파일 다운로드이며 운영 설치나 센서 수신 시험이 아닙니다.

## 데이터를 저장하고 이전 상태로 되돌릴 수 있나요?

**Local Versions**에서 최대 30개의 브라우저 로컬 체크포인트를 저장·비교·복원할 수 있습니다. 로그가 브라우저에서 자동으로 암호화되는 것은 아닙니다.

## Python 테스트 송신기는 어떤가요?

**Generate a Python Test Sender**에서 기본 라이브러리 기반 파일을 내려받을 수 있습니다. 실행자가 승인된 센서 IP·포트·프로토콜 등을 직접 입력하고 YES로 전송을 승인합니다. 파일 다운로드만으로 송신되지는 않습니다.

## 영어 제품 화면을 한국어 설명서로 따라갈 수 있나요?

네. 설명 문장은 한국어이며, 버튼명은 제품 화면의 영어 원문 그대로 표기했습니다. [한국어 빠른 시작](/ko/quickstart)을 보세요.
