# 로그 원본과 개인정보를 보호하세요

고객 로그에는 IP 주소, 사용자명, 이메일, 토큰, 시스템 이름이나 비밀값이 포함될 수 있습니다. 학습에는 예제 로그를 사용하고, 고객 원본을 입력하기 전에 적절한 권한이 있는지 확인하세요.

## 브라우저와 Parser Studio 서버 분석의 차이

로그 입력 및 초기 브라우저 미리보기와 **Local Versions**는 현재 브라우저에서 작동합니다. 하지만 **Analyze Logs**를 누르면 **원본 샘플이 같은 출처의 Parser Studio 서버로 POST 전송**되어 Multi-Pass 분석에 사용됩니다.

- **Parser Studio 서버:** Analyze Logs 실행 시 원본을 받습니다. 브라우저 안에서만 처리되는 기능이 아닙니다.
- **외부 ChatGPT:** Auto Parser나 ChatGPT Assisted가 원본을 **자동 전송하지 않습니다**. 사용자가 별도 창에 프롬프트를 직접 붙여 넣는 경우에만 외부 공유가 발생합니다.
- **Upload a log file:** 파일은 먼저 브라우저에서 읽고, 이후 Analyze Logs 실행 시 선택한 로그가 Parser Studio 서버에 전달됩니다.

**외부 AI 자동 전송이 없다는 설명을 서버 전송도 없다는 뜻으로 이해하면 안 됩니다.** 고객 로그의 반출·분석 승인 여부를 확인하세요.

## ChatGPT Assisted Parser

현재 화면에는 **Original local logs** 입력칸이 하나 있습니다. 별도의 **Redacted example** 편집 영역이나 마스킹 승인 메뉴는 없습니다.

**Prepare ChatGPT Prompt**는 입력한 원본 로그를 그대로 포함합니다. **BEGIN ORIGINAL LOG SOURCE** 블록까지 프롬프트 전체를 확인한 후 **Copy Prompt**를 수동으로 사용하세요. 외부 공유가 불가능한 값이 있다면 원본에서 먼저 수정하거나 삭제해야 합니다. 이 경우 테스트 입력이 변경되므로 원본·Holdout 검증을 다시 수행합니다.

**Fix with ChatGPT** 프롬프트도 실제 미파싱 원문을 포함할 수 있으므로 복사 전 검토하세요.

## Local Versions 및 Python 테스트 송신기

Local Versions에는 현재 브라우저 프로필에 원본 로그와 규칙이 저장될 수 있으며 Parser Studio가 별도로 암호화하지 않습니다.

**Generate a Python Test Sender**로 내려받는 파일에는 샘플이 **base64(암호화 아님)** 로 저장될 수 있습니다. 다운로드만으로 센서 송신이 시작되지는 않습니다. 외부 배포·실행 전에 파일 내용을 검토하세요.
