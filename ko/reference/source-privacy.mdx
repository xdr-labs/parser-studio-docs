# 로그 원본과 개인정보를 보호하세요

보안 로그에는 IP 주소, 사용자명, 이메일, 정책명, 원본 시스템 식별자 등이 있을 수 있습니다.

## Auto Parser의 기본 동작

**Analyze Logs**는 자동으로 외부 ChatGPT 서비스에 로그를 보내지 않습니다. 사용자가 선택하는 기능에 따라 같은 서비스 출처의 서버 분석을 사용할 수 있으므로, **브라우저에만 존재한다는 표현과 절대적으로 서버 전송이 없다는 주장은 구분**해야 합니다.

원본을 유지할 때는 허용된 브라우저·PC와 승인된 로그만 사용하세요. 64 KiB/500 이벤트 상한과 원본 파일의 줄 경계도 고려하세요.

## ChatGPT Assisted Parser

- **Original local logs:** 제품에서 테스트할 원본입니다.
- **Redacted example to copy to ChatGPT:** 외부 공유용으로 사용자가 직접 민감값을 바꾼 예시입니다.
- **Prepare ChatGPT Prompt / Copy Prompt:** 사용자 수동 조작을 통해 외부 ChatGPT에 전달합니다.
- **Fix with ChatGPT:** 원본 텍스트와 미파싱 영역이 들어 있는 프롬프트가 만들어질 수 있습니다. 복사 전 반드시 검토해야 합니다.

제품은 로그를 AI 제공업체에 자동으로 전송하지 않습니다.

## Local Versions·테스트 송신기

브라우저 로컬 버전 기록에는 원본 로그와 규칙이 저장될 수 있고 **Parser Studio가 따로 암호화하지 않습니다.** 공유 브라우저 프로필에서 유출되지 않도록 관리하세요.

테스트 송신기 파일에는 샘플 로그가 **base64 인코딩(암호화 아님)** 으로 포함될 수 있습니다. 외부 공유 전에 삭제 또는 마스킹해야 합니다.
