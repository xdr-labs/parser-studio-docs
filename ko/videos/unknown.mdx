## 따라 하기

1. Manufacturer에 Snort, Product에 Snort 3를 입력하고 원본 한 건만 붙여 넣습니다.
2. Analyze Logs에서 0 of 1 log event parsed completely를 확인합니다.
3. Fix with ChatGPT를 눌러 원본과 현재 인식된 값을 보존하는 프롬프트를 검토합니다.
4. 교육용 JSON 파일은 영상에 사용된 검토 제안입니다. 외부 ChatGPT 결과를 자동 승인하는 파일이 아니므로 직접 확인하세요.
5. 별도 로그 두 건을 Additional test logs에 넣고 Confirm different test examples를 선택합니다.
6. Test Proposed Fix를 통과하면 Approve tested fix를 선택하고 Apply Tested Fix를 누릅니다.
7. Review Fields → Map Fields → Create Parser에서 1/1 완전 파싱을 재검증하고 파일을 받습니다.

## 예상 결과

처음에는 0/1이며, 제안 규칙을 독립된 두 사례로 검증하고 승인한 다음 1/1 완전 파싱과 최종 파일 생성이 통과합니다.
