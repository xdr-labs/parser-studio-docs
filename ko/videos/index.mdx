## 처음 실습한다면

**다운로드 없이 바로 복사:** 아래 각 영상 페이지에 **영상과 동일한 원본 로그를 복사할 수 있는 코드 블록**을 추가했습니다. Snort 복구는 별도의 검증용 로그와 교육용 JSON도 제공합니다.



1. [공개 원본 로그 전체 ZIP 다운로드](https://app.parser.xdr.ooo/training/parser-studio-real-scenarios-20261021/practice/practice-all.zip)
2. [Parser Studio 열기](https://app.parser.xdr.ooo/)
3. 원하는 영상을 선택하고 동일한 원본 로그를 입력합니다.
4. 각 영상 페이지의 타임스탬프를 이용해 일시 정지하면서 따라 합니다.
5. 예상 결과가 다르면 이벤트를 삭제하거나 성공으로 표시하지 말고 오류를 확인합니다.

<Note>
제품 UI는 영어입니다. 한글 설명서에는 실제 버튼 이름을 영어로 그대로 표기합니다. 성공한 샘플이 모든 장비·펌웨어의 호환성을 보증하지는 않습니다.
</Note>
