이 파일에는 영상에서 사용한 원본 샘플이 들어 있습니다. 불완전한 이벤트를 삭제하거나 변경하면 영상과 같은 결과를 비교할 수 없습니다.

## 따라 하기

1. Manufacturer에 Juniper, Product에 SRX를 입력합니다.
2. 원본 로그 파일의 두 이벤트를 Add Logs에 그대로 붙여 넣습니다.
3. Analyze Logs를 눌러 2 of 2 log events parsed completely 결과를 확인합니다.
4. Review Fields에서 원본과 추출된 주소, 정책, 포트 및 세션 ID를 비교합니다.
5. Map Fields에서 Stellar Cyber 7.0의 필드명과 자료형을 확인합니다.
6. Create Parser → Run Final Test & Create Files로 전체 샘플을 검증한 뒤 패키지를 받습니다.

## 예상 결과

2건 중 2건이 완전 파싱되고, 최종 샘플 테스트와 파서 파일 생성이 통과합니다.
