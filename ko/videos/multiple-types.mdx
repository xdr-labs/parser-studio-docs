## 따라 하기

1. Auto Parser에서 Manufacturer는 Fortinet, Product는 FortiGate로 설정합니다.
2. Add Another Log Type를 눌러 두 그룹을 만들고 이름을 Traffic과 Threat로 지정합니다.
3. Traffic 샘플 두 건과 Web Filter/IPS 두 건을 각각 알맞은 그룹에 입력합니다.
4. Analyze Logs로 4 of 4 log events parsed completely를 확인합니다.
5. Review Fields에서 각 이벤트의 type, subtype 및 서로 다른 필드를 확인합니다.
6. Optional: one parser for several event types에서 확인된 분기 필드가 실제로 적절한지 검토합니다.
7. Map Fields에서 Stellar Cyber 7.0 매핑을 검토한 후 Run Final Test & Create Files로 네 건 모두 재검증합니다.
