# Words you may see on the screen

You do **not** need to learn every technical term to create a parser. This page translates common words into everyday explanations.

| Term | What it means for you |
| --- | --- |
| **Log / Event** | One security record from your firewall, application or other product |
| **Sample logs** | A few representative records you pasted for Parser Studio to examine |
| **Analyze Logs** | The button that attempts to read and separate the values in your sample |
| **Parser** | The instructions for understanding the values inside an event |
| **Field** | One piece of information such as the action, IP address, port or username |
| **Source field** | The field as it originally appears in the device's log |
| **Mapping** | Choosing where the extracted value should go in the output |
| **Target field** | The destination name selected during Map Fields |
| **Stellar field catalog** | Available standard field names you can choose from during mapping |
| **Vendor/custom field** | A place to keep a value when its exact standard meaning is unknown |
| **Logical event** | One complete source record, which might span more than one line |
| **Partially parsed** | Some values were recognized but another section still needs review |
| **Format** | How text is arranged, for example JSON, CEF, LEEF or comma-separated values |
| **CSV** | Values arranged in ordered columns, sometimes with no column names |
| **Syslog header** | The date, host and metadata at the start of some records |
| **ParserRecipe v0.2** | The supported structured JSON response used in the ChatGPT-assisted path |
| **Holdout / Additional test logs** | Different sample records used to check that a proposed fix works beyond the original example |
| **Draft** | A reviewable parser output created from supported source examples |
| **Ruby logic + CONF** | The two matching files that can be downloaded after successful generation |
| **SHA-256** | A value used to check whether downloaded output matches the generator's expected bytes |
| **Local Versions** | Saved parser experiments stored in the current browser environment |

## When should I learn the technical format name?

Only when your source documentation uses one, or when an error needs more context. A new user should **paste the logs and press Analyze Logs first**.
