# What happens to the logs I paste?

Security event logs may contain usernames, hostnames, addresses, email addresses, request paths or secrets. Choose fictional examples while learning and review private data carefully during real authoring.

## When you click Analyze Logs

**Auto Parser** examines the pasted or uploaded sample using the local analysis workflow. Ordinary analysis is not an automatic external ChatGPT request. The product may request same-origin service capabilities or analysis, depending on the selected operation.

Do not assume that a displayed source is suitable for public sharing. Treat pasted customer logs as sensitive.

## When you use ChatGPT Assisted Parser

There are **two separate places** on that screen:

- **Original local logs**: source events kept for local analysis and checking.
- **Redacted example to copy to ChatGPT**: the visible example you may choose to share manually.

1. Inspect the redacted example. A prefilled fictional example does **not** guarantee that the content you add is safe.
2. Remove or replace confidential identifiers.
3. Click **Prepare ChatGPT Prompt** and read the entire resulting text.
4. Click **Copy Prompt** only if you intend to share what is visible.
5. Open ChatGPT yourself and paste the prompt.

No automatic external model request is performed by this workflow. An inline **Fix with ChatGPT** prompt can contain original source fragments—**redact it before copying**, too.

## When you download the Python test sender

The standalone Python file contains the sample logs encoded as **base64, not encryption**. Someone with the file may decode the values. Supported fields can be varied for testing, but not all sensitive values are necessarily transformed.

## Safe practice examples

Use documentation-only addresses such as `192.0.2.10`, `198.51.100.20`, and `203.0.113.30`; use a fictional user like `demo-user` and email under `example.test`.

## When you save Local Versions

Saved working versions belong to the current browser environment. They are not a shared backup. Review who has access to that browser and keep an independent copy of important approved outputs.
