### Follow the current on-screen steps

1. Open **Auto Parser**, enter manufacturer **Snort** and product **Snort 3**, then paste only the one original alert.
2. Click **Analyze Logs** and inspect the **0 of 1 log event parsed completely** result. Preserve the whole alert and its unparsed regions.
3. Use **Fix with ChatGPT** and inspect the generated source-bearing prompt. **Prepare ChatGPT Prompt**, then **Copy Prompt** only after confirming that external sharing is allowed.
4. The new recording ends at the prompt-review stage; it does **not** pretend an external ChatGPT result was returned. To continue yourself, paste the model response into **ChatGPT result JSON** and select **Check ChatGPT Result**.
5. For a reviewable proposal, add the two independent holdout alerts under **Different examples to test the fix** and check **Confirm test examples are different**. Test before applying or downloading. The optional recipe displayed above is educational, not automatically trusted.

## Expected review outcome

The original Snort alert_fast sample is not fully parsed at first. The updated video demonstrates the actual prompt preparation and privacy boundary; an external ChatGPT answer and independent holdout validation remain separate user steps.

Do not treat successful source extraction or generated files as evidence of full vendor/firmware coverage, target import acceptance, or live Stellar Cyber deployment compatibility.

## Recovery path

For a different log shape, keep the original records and examine the highlighted source spans, following the [related workflow](/scenarios/unknown-log). Only apply additional parsing rules after different examples pass a separate regression test. Never delete failing events merely to obtain a passing total.
