### Follow the on-screen steps

1. Open Auto Parser in another tab. Enter Manufacturer: Snort and Product: Snort 3.
2. Paste ONLY the single original line from 03-snort-alert.log into Add Logs and click Analyze Logs. Do not include the separate holdout lines yet.
3. Choose Fix with ChatGPT. Review the generated prompt and manually redact any confidential information before choosing to share it.
4. The optional JSON file is the exact reviewed demo proposal. Paste its contents into ChatGPT JSON result only if you understand the restrictions; it is not an automatically trusted AI output.
5. Paste the two different lines from 03-snort-holdout.log into Additional test logs. Check Confirm different test examples, then click Test Proposed Fix.
6. Approve a passing result before clicking Apply Tested Fix. Continue through Review Fields, Map Fields, and Create Parser; run the final test before downloading any file.

**Expected sample result:** 0 of 1 log event parsed completely at first; after an independently reviewed and approved fix, 1 of 1 completely parsed.

## Expected review outcome

The original Snort alert_fast sample is not fully parsed at first. A bounded, reviewed parser proposal passes a two-example independent holdout check and the final sample test.

Do not treat successful source extraction or generated files as evidence of full vendor/firmware coverage, target import acceptance, or live Stellar Cyber deployment compatibility.

## Recovery path

For a different log shape, keep the original records and examine the highlighted source spans, following the [related workflow](/scenarios/unknown-log). Only apply additional parsing rules after different examples pass a separate regression test. Never delete failing events merely to obtain a passing total.

## Original log provenance

- [Official Snort 3 Rule Writing Guide: Alert Logging](https://docs.snort.org/start/alert_logging)

<Note>
Customer logs may include private information. Review, sanitize and manually approve any excerpt before copying it into an external ChatGPT conversation. The Auto Parser does not automatically share those logs.
