### Follow the current on-screen steps

1. Open **Auto Parser**, enter manufacturer **Fortinet** and product **FortiGate**.
2. Choose **Add Another Log Type**. Name the two groups **Traffic** and **Threat**, preserving two published source events in each group.
3. Click **Analyze Logs** and check all four events; the recorded source review returned **4 of 4 log events parsed completely**.
4. In **Review Fields**, inspect event-specific values for Traffic, Web Filter and IPS. Continue to **Map Fields** and verify each mapping against the actual source.
5. If the product accepts the shared parser draft, proceed to **Create Parser**, run **Run Final Test & Create Files**, then download and review the package. A successful sample test cannot prove all FortiGate event shapes.

## Expected review outcome

Four original Fortinet documentation log examples parse completely in one project. The final four-event test and package generation pass.

Do not treat successful source extraction or generated files as evidence of full vendor/firmware coverage, target import acceptance, or live Stellar Cyber deployment compatibility.

## Recovery path

For a different log shape, keep the original records and examine the highlighted source spans, following the [related workflow](/scenarios/mixed-events). Only apply additional parsing rules after different examples pass a separate regression test. Never delete failing events merely to obtain a passing total.
