## Walkthrough

1. Open Auto Parser and enter Juniper / SRX as the source product.
2. Paste two RT_FLOW records from the upstream Juniper SRX test corpus.
3. Choose Analyze Logs and verify that both source events parse completely.
4. Under Review Fields, confirm source and destination addresses, protocol, policy and session ID.
5. Review suggested Stellar Cyber 7.0 dictionary mapping in Map Fields.
6. Run the final test and download the reviewed parser package.

## Expected review outcome

Both publicly available Juniper SRX events parse completely; final sample validation and parser package download succeed.

Do not treat successful source extraction or generated files as evidence of full vendor/firmware coverage, target import acceptance, or live Stellar Cyber deployment compatibility.

## Recovery path

For a different log shape, keep the original records and examine the highlighted source spans, following the [related workflow](/scenarios/auto-success). Only apply additional parsing rules after different examples pass a separate regression test. Never delete failing events merely to obtain a passing total.
