### Follow the current on-screen steps

1. Open **Auto Parser** and enter **Manufacturer: Juniper**, **Product: SRX**. The firmware version of these examples is not asserted.
2. Paste both unchanged source records into **Add Logs** and click **Analyze Logs**. Verify **2 of 2 log events parsed completely**.
3. Enter **Review Fields**, check the original IP addresses, source/destination zones, session IDs and action against the full source, then open **Map Fields**.
4. Verify the Stellar Cyber 7.0 mapping suggestions and vendor-specific values; continue to **Create Parser**.
5. Click **Run Final Test & Create Files**. Only after it succeeds, choose **Download Parser Package**. No live target installation is implied.

Both publicly available Juniper SRX events parse completely; final sample validation and parser package download succeed.

## Recovery path

For a different log shape, keep the original records and examine the highlighted source spans, following the [related workflow](/scenarios/auto-success).
