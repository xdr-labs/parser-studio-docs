### Follow the on-screen steps

1. Open Auto Parser in a second tab and enter Manufacturer: Juniper and Product: SRX. Use the same sample file as in the recording.
2. Open the log file in a text editor, select its complete contents (both original RT_FLOW events), and paste it into Add Logs. Do not manually change the event boundaries.
3. Click Analyze Logs. Check that both sample events parse completely. Continue to Review Fields, Map Fields, and Create Parser.
4. Run Final Test & Create Files, then download the parser package. Passing these samples does not prove live Stellar Cyber compatibility.

**Expected sample result:** 2 of 2 log events parsed completely.

Both publicly available Juniper SRX events parse completely; final sample validation and parser package download succeed.

Do not treat successful source extraction or generated files as evidence of full vendor/firmware coverage, target import acceptance, or live Stellar Cyber deployment compatibility.

## Recovery path

For a different log shape, keep the original records and examine the highlighted source spans, following the [related workflow](/scenarios/auto-success). Only apply additional parsing rules after different examples pass a separate regression test. Never delete failing events merely to obtain a passing total.
