## Walkthrough

1. Paste two long original Sophos Firewall source records and click Analyze Logs.
2. Inspect the highlighted regions that prevent complete source extraction.
3. Expand Values already found to examine fields that must remain unchanged.
4. Open Tools & Diagnostics and choose Re-analyze difficult logs.
5. Select Review unparsed text when the exact residual range is available.
6. Use Fix with ChatGPT to prepare a focused additional parsing rule and redact any sensitive data before copying.
7. Test a proposed rule against different events; do not export until all blocking errors are resolved.

## Expected review outcome

The original long Sophos Firewall examples retain dozens of recognized source values, but neither sample is fully parsed. The video demonstrates diagnosis and the additional-rule workflow without claiming an unverified repair succeeded.

Do not treat successful source extraction or generated files as evidence of full vendor/firmware coverage, target import acceptance, or live Stellar Cyber deployment compatibility.

## Recovery path

For a different log shape, keep the original records and examine the highlighted source spans, following the [related workflow](/scenarios/partial-event). Only apply additional parsing rules after different examples pass a separate regression test. Never delete failing events merely to obtain a passing total.
