### Follow the on-screen steps

1. Open Auto Parser in another tab. Enter Manufacturer: Sophos and Product: XG Firewall.
2. Open the sample file and paste both original long firewall records into Add Logs. Keep their wording, unusual separators and empty values intact.
3. Click Analyze Logs. Open Problem to review and expand Values already found: some fields are valid while the remaining source spans still require review.
4. Open Tools & Diagnostics, select Re-analyze difficult logs, and choose Review unparsed text if the exact residual source region is available.
5. Select Fix with ChatGPT to prepare a focused reviewed prompt. Only use a manually redacted, user-approved excerpt with external ChatGPT.
6. Do not claim success or download a parser while blocking residuals remain. Any additional rule must be tested on different events before explicit approval.

**Expected sample result:** 0 of 2 log events parsed completely (but many original field values extracted).

## Expected review outcome

The original long Sophos Firewall examples retain dozens of recognized source values, but neither sample is fully parsed. The video demonstrates diagnosis and the additional-rule workflow without claiming an unverified repair succeeded.

Do not treat successful source extraction or generated files as evidence of full vendor/firmware coverage, target import acceptance, or live Stellar Cyber deployment compatibility.

## Recovery path

For a different log shape, keep the original records and examine the highlighted source spans, following the [related workflow](/scenarios/partial-event). Only apply additional parsing rules after different examples pass a separate regression test. Never delete failing events merely to obtain a passing total.
