## Follow along with the same samples

**Copy without a file download:** Every tutorial below also includes the **exact original log text in copyable blocks** immediately beneath its video, plus separate holdout alerts for the Snort case.



1. [Download the original practice logs, holdout examples and source credits](https://app.parser.xdr.ooo/training/parser-studio-current-20261031/practice/practice-all.zip).
2. Keep your chosen training video open and [launch Parser Studio](https://app.parser.xdr.ooo/) in another browser tab.
3. Open the relevant sample log file, copy its original event lines, and follow the click-by-click practice instructions directly below each embedded video.
4. Pause or seek using the chapter timestamps shown on that video's documentation page. Compare the actual parser results to the recorded expected behavior.

**The Sophos partial-parsing exercise is intentionally unresolved:** the point is to locate unsupported text while preserving recognized fields, not to force a false success state. The included Snort JSON proposal is optional and still requires review, independent tests and explicit approval.

## What these examples demonstrate

- **RFC3164 relay:** two synthetic security events wrapped with variable relay headers are recognized only after explicitly declaring `relay01`; original source bytes stay available for review.

- **Juniper SRX:** complete extraction, field mapping and parser-file creation from published RT_FLOW examples.
- **Sophos XG:** dozens of source values recognized in a complex log while unresolved text still requires an additional reviewed parsing rule.
- **Snort 3:** a real alert_fast line that needs a tested, explicitly approved ChatGPT-assisted recipe.
- **FortiGate:** combined Traffic, Web Filter and IPS samples; the documented traffic and web-filter examples share a session ID.

<Warning>
Successful source extraction in these samples does not prove native parser compatibility for every firmware or a verified live Stellar Cyber target installation. Never claim unsupported source regions were parsed or silently discard events.
</Warning>
